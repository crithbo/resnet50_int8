# ADR-021：按上游 Git 来源收窄配置正确性授权

日期：2026-07-23

状态：accepted；本决策取代 ADR-020 对 `ndp-sim/jsons` 整个目录的宽泛授权。

## 1. 用户澄清

DeepSeek 算子一般均经过硬件测试，配置证据力度较高，但 `ndp-sim/jsons` 中只有云端
仓库固定版本原生自带、且当前内容仍与该提交一致的配置，才可作为正确并经过测试的配置。
后来加入的算子（明确示例为 `node0004`）没有因此获得“经过测试并正确”的授权。

根仓 `jsons` 中可识别的用户参考算子配置继续按正确参考配置处理。

## 2. Git 逐文件分类

活动仓库固定为：

```text
https://github.com/uSFrances/ndp-sim.git
ec12424516ae0304228dd2321d4e604fe225e04e
```

当前机器分类结果：

- `ndp-sim/jsons` 共 55 份 JSON；
- 53 份由固定提交跟踪且工作树与提交一致，接受为上游已测试正确基线；
- `node0004_accumulate_wave0.json` 与
  `node0004_accumulate_wave0_nopp_r1.json` 是提交之外的项目新增文件，不在授权内；
- 根仓 `jsons` 中 12 份可识别算子配置继续按用户提供的正确参考配置处理。

因此当前 67 份库存中共有 65 份授权正确参考、2 份项目新增未授权候选。分类依据必须是
固定提交中的路径和 Git 内容身份，不能根据文件所在目录、文件名或可解析性自动认定。

## 3. 使用边界

65 份授权配置可用于字段语义、LC/PE/stream/buffer/SA/GA 拓扑、同族 ScheduleIR、
规则提炼、已知配置反向复现和新候选种子，不再要求先找到逐文件原始服务器日志。

两份项目新增 `node0004*` 配置只能用于：

- 身份和来源审计；
- 失败定位；
- 带有显式边界的静态结构假设。

在独立验证通过前，它们不得用于解除 Conv 配置正确性 blocker。现有硬件负证据和无效
尝试必须原样保留。

无论源参考配置是否授权正确，新 shape、地址、常量、拓扑、跨 stage 状态及 ResNet50
派生候选仍须通过严格本地链、独立 golden 和服务器 E4/E5，才能晋升为正式配置。
