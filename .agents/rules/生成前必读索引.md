# 生成前必读索引

最后更新：2026-08-18

本文件只路由“本轮读什么、何时停止、证据到哪一级”。它不定义字段公式、服务器实现或算子
结果；唯一语义 owner 见 `contracts/active_rule_registry_v1.json`，历史规则默认不读。

## 1. 每轮固定入口

先完整读取 `.agents/agent.md`、current `.agents/plan.md` 和本索引。再从
`contracts/current_session_owner_registry_v1.json` 确认 role/write scope，按 changed surface 选读。
同一文件同轮只读一次，receipt 记录 path+reason；SHA 不是阅读完成条件。

## 2. 按动作选读

| 动作 | 必读 | 条件增量 |

| complete JSON、mapping、bitstream、execplan、SCA | `算子配置规则.md`、`NDP硬件字段语义.md`、目标族/原语规则 | 实际调用的 handler/mapper/encoder/planner/consumer |
| 构建或修补服务器包 | `服务器测试包生成规则.md`、项目 Skill、`NDP_copy01/README_HARDWARE_SIM_ENTRY.md` | config/workload 真变更时才加配置与族规则 |
| 分析 return、设计 successor | 服务器规则结果/连续闭环章节、目标族动态门 | 只在解释首分歧时读 actual config consumer/compiled RTL cone |
| 会话换届/接手 | `会话转接与所有权规则.md`、current owner registry | role 对应规则、current pointer/latest record |
| 整网收敛/规则事故 | `整网测试收敛优化专项规则.md`、唯一语义 owner | machine report、tool/schema/test；先 incident adjudication |
| 工作区瘦身/迁移 | `整网测试收敛优化专项规则.md`、workspace lifecycle policy/tool | current owner registry、storage index、protected-set、迁移清单 |
| 功能 RTL repair | 目标配置/硬件/服务器规则 | 必须有用户本轮明确 RTL 授权 |

`.codex/skills/resnet50-server-package-flow/SKILL.md`。Skill 不可用时显式读它并执行同一命令。

## 4. 公共停止门

以下任一成立立即停止当前生成/发布并报告最后可信边界：

1. target stage、typed request、qparam、layout、workload 或 actual consumer identity 不完整；
2. required leaf 无唯一 owner、被隐式补零、handler 对 changed axis 无能力，或 composition 未闭合；
3. 准备从失败包、服务器残留、停用规则或未知来源补文件；
4. 地址/transaction/bank-row/lifetime/terminal/formal-D 无法绑定实际 consumer；
5. 准备把 E0/E1/E2、partial、内部 write 或 expected equation 当成 E4/E5；
6. 无用户授权却要改 RTL/ISA/硬件、上传/运行服务器、取 lease 或改变外部状态；
7. 服务器包未调用 Skill/`prepare`/`admit`，或 blocking finding 不能映射到
   `server_start`、`actual_input`、`state_safety`、`return`；
8. 实际 package-owned shell/Python/HDL 不能解析、actual input 路径矛盾、runner/finalizer/return 不完整；
   服务器 vendor 工具/文件当前不存在本身不构成本地阻断；
9. package 已执行/绑定 return 却准备原地覆盖，或 unrun patch 准备重建未变资产/重跑已 PASS 门；
10. 诊断 candidate matrix 不可区分、actual signal 非 source-bound，或 partial evidence 被冒充 natural/D；
11. owner registry/plan/storage current 指针漂移、重复 ACTIVE owner 或主线路由仍硬编码旧 task；
12. active-rule audit 或 current-disk takeover readiness 不通过。
13. 准备删除/移动内容却没有 current protected-set、owner writer quiescence、exact quarantine plan 和
    post-quarantine verification；未知、拒绝访问或 reparse 路径不得靠名称/年龄放行。

## 5. 证据等级与回归分类

- E0：静态可解析/可编码；
- E1：来源、结构、mapping、bitstream、execplan、地址和确定性闭合；
- E2：独立软件公式、layout、golden 与最终物化回环闭合；
- E3：绑定身份的服务器运行自然完成；
- E4：正式 readback 与独立 golden 一致；
- E5：全新身份重复运行并覆盖专项边界，可推广。

只有同门动态 known-good 才称 `REGRESSION`；只有本地/静态基线称 `NO_DYNAMIC_BASELINE`；首次
服务器失败称 `FIRST_DYNAMIC_FAILURE`。reuse 不是新的 E 级。
